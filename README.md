# JUSTICE ROOM · 청소년 법률 RPG

Next.js App Router + TypeScript + Tailwind CSS + Zustand + HTML5 Canvas로 구현한 다섯 사건의 플레이 가능한 로컬 게임입니다. 별도 이미지 요청 없이 도트 마을과 캐릭터를 직접 렌더링합니다.

## 실행

```powershell
cd justice-room
npm ci
npm run dev
```

http://localhost:3100 에서 플레이합니다. 배포용 빌드는 `npm run build`, 실행은 `npm start`, 규칙 테스트는 `npm test`입니다. Next.js 텔레메트리를 끄려면 `NEXT_TELEMETRY_DISABLED=1`을 설정합니다.

## 구현 범위

- 다섯 시나리오별 3장면 Canvas 프롤로그, 타이핑 대사, 건너뛰기, 선택형 칩튠 BGM.
- 마을/실내 이동, 방향키·WASD·터치 D-pad, 건물 충돌, 클릭 핫스팟 및 E 조사.
- INSPECT / PASSCODE / ITEM_USE 퍼즐과 내용증명 필수 항목 맞추기.
- 드래그 또는 클릭으로 두 원본을 선택해 자료집 합성. 원본은 남으며 중복 획득·합성은 금지.
- 용돈 30만 원, 요건 충족도, 적법성, 증명력, 24턴 제한, 상담, 구제기관 잠금.
- 사건별 결과와 재시작, 조문 정확도(S~C) 등급.
- **형사 사건(사기)은 조문 퍼즐로 진행**: 핸드북에서 법전 카드(형법·형사소송법·통신비밀보호법)를 모으고, ① 적용 조문 고르기 → ② 고소 접수(제223·237조) → ③ 사기죄 요건(기망·재물의 교부·재산상 손해·고의)을 증거로 입증 → ④ 증거+조문을 함께 내서 진술 반박 → ⑤ 불송치 이의신청(제245조의6·7)을 풀면 조문 정확도(S~C)가 나옵니다. 몰래 녹음한 제보 파일을 쓰면 통신비밀보호법·형사소송법 제308조의2로 막힙니다. 데이터는 `src/lib/criminal.ts`.
- **계약 사건(미성년자 계약 취소)도 조문 퍼즐**: 법률 책자에서 민법 카드를 모으고 ① 취소 근거(제5조) → ② 취소권자·방식(제140·142조) → ③ 취소 요건(미성년자·동의 없음·처분 허락 범위 초과·속임수/추인 없음)을 증거로 입증 → ④ 환불 불가·동의·속임수 주장을 증거+조문으로 반박(제141·5·17조) → ⑤ 소액사건·민사조정·미성년자의 소송능력(소액사건심판법 제2조, 민사조정법 제2·29조, 민사소송법 제55조)을 풀면 등급이 나옵니다. 환불 불가 약관 사진은 어느 요건도 채우지 못하는 미끼 증거입니다. 데이터는 `src/lib/contract.ts`.
- **노동 사건(부당해고·주휴수당)도 조문 퍼즐**: 노동법 책자에서 근로기준법 카드를 모으고 ① 해고 근거(제23조 제1항) → ② 구제신청(제28조, 3개월) → ③ 부당해고 요건(근로자임 제2조·5명 이상 사업장 제11조·해고 사실과 서면통지 제27조·정당한 이유 없음 제23조)을 증거로 입증 → ④ "학생은 근로자 아님"(제2조), "학생은 주휴수당 없음"(제55조, 시행령 제30조 개근, 제18조 제3항 15시간 예외), "해고에 서면 불필요"(제27조)를 증거+조문으로 반박 → ⑤ 구제명령(제30조)과 체불 임금 신고(제104조)의 별도 절차를 풀면 등급이 나옵니다. 사장·점장의 대화를 몰래 녹음한 USB는 통신비밀보호법으로 막히는 함정입니다. 데이터는 `src/lib/labor.ts`.
- **민사 사건(킥보드 손해배상)도 조문 퍼즐**: 민법 제750조(고의·과실, 위법행위, 손해, 인과관계)를 증거로 입증하고, 제763조가 준용하는 제393조(손해배상의 범위)·제396조(과실상계)로 반박하며, 제766조(소멸시효)와 소액사건심판법(제2·4·5조의3)을 퀴즈로 다룹니다. 가해자 SNS에 몰래 접속해 얻은 대화는 정보통신망법 제49조로 막히는 함정입니다. 데이터는 `src/lib/tort.ts`.
- **헌법 사건(가상 셧다운법)도 조문 퍼즐**: 헌법 제37조 제2항에서 도출되는 과잉금지원칙의 4단계(목적·적합성·최소성·균형성)를 자료로 하나씩 입증하고, 헌법 제10조(행복추구권), 헌법재판소법 제25·69·70조(변호사 대리·청구기간·국선대리인), 제75조·제47조(위헌결정과 효력)를 다룹니다. 헌법재판소법은 2026. 3. 12. 개정된 현행 문구를 반영했습니다. 데이터는 `src/lib/constitution.ts`.
- 다섯 사건이 모두 `LawCase` 설정(`src/lib/lawtypes.ts`, `lawcases.ts`)으로 같은 화면·규칙(`LawTrial.tsx`, `store.ts`)에서 동작합니다. 새 사건은 `LawCase`를 만들어 `lawcases.ts`에 등록하면 됩니다.
- 기기 내 자동 저장, 버전 및 저장값 검증. Supabase 설정 시 익명 계정별 수동 저장/불러오기.
- 모바일 반응형 UI, 모달 포커스 제한, ESC 닫기, 키보드 입력, 법률 노트와 공식 출처.

## Supabase 연결

현재 원격 프로젝트에는 스키마를 적용하지 않았습니다. 기존 워크스페이스의 다른 서비스 자격증명은 재사용하지 않습니다.

1. 새 프로젝트 SQL Editor에서 `supabase/schema.sql` 실행 후 `supabase/seed.sql`을 실행합니다.
2. Auth에서 Anonymous Sign-Ins를 활성화합니다.
3. `.env.example`을 `.env.local`로 복사하고 프로젝트 URL과 publishable key를 입력합니다.
4. 서버를 재시작하고 저장 관리에서 클라우드 저장/불러오기를 확인합니다.

`game_sessions`의 JSON 상태에 인벤토리·퍼즐 해결 상태·턴·스탯을 저장합니다. RLS는 본인의 `auth.uid()` 행만 읽기/삽입/수정하도록 제한합니다. 정적 콘텐츠 테이블 6개는 읽기 전용입니다. 서비스 역할 키는 클라이언트에 사용하지 않습니다. 익명 계정은 같은 브라우저의 인증 세션에 묶이므로 다른 기기 동기화에는 별도의 계정 연결 기능이 필요합니다.

현재 게임 콘텐츠는 `src/lib/scenarios.ts`의 번들 데이터를 사용하며 SQL seed와 동일한 원본입니다. DB에서 편집한 시나리오를 런타임에 내려받는 CMS 기능은 포함하지 않습니다. seed 재생성은 `npx tsx scripts/seed.ts`. 실제 연결 정보가 제공되지 않아 원격 DB 및 RLS 실행 검증은 수행하지 않았습니다.

## Higgsfield 장면 연결 및 게임성 통합

GitHub `01389b3`의 다섯 사건 조문 퍼즐과 법률 데이터를 유지하면서 탐색·심문 연출을 확장했습니다.

- 바닥 클릭 시 장애물을 피해 걷고, 가까운 오브젝트 이름이 E 버튼에 표시됩니다. 방향키·WASD·터치 패드와 직접 핫스팟 조사도 지원합니다. 걷기는 턴을 소모하지 않습니다.
- 현재 목표와 조사 진행도, 새 증거 알림, 조사·합성 효과음, 심문 배경음, 모순 확인 진행 표시를 추가했습니다.
- 사건별로 **프롤로그 → 이의 있음 → 상대 반응 → 에필로그** 영상을 연결합니다. 정답 반박은 이의 있음과 상대 반응을 연속 재생합니다. 영상이 없거나 재생에 실패하면 도트 연출로 진행합니다.
- 기존 게임 저장의 누락된 조문 진행 필드를 보완하며, 연출 설정은 게임 저장과 별도로 보관합니다.

상단 필름 아이콘의 **연출 보관함**에서 사건과 장면을 선택하고 Higgsfield에서 완성된 공개 HTTPS MP4/WebM 주소를 적용하세요. 각 장면의 생성 프롬프트를 복사하고 미리 볼 수 있습니다. 브라우저에서 적용한 주소는 해당 기기에만 저장됩니다.

모든 플레이어에게 적용하려면 **연출 설정 내보내기**로 받은 파일을 `public/cinematics/manifest.json`에 반영하세요. 직접 소유한 영상 파일은 `public/cinematics/`에 두고 `/cinematics/파일명.mp4`로 연결할 수 있습니다. 설정 우선순위는 기기의 개별 사건 → 배포된 개별 사건 → 기기의 공통 영상 → 배포된 공통 영상입니다. 기존 `NEXT_PUBLIC_OBJECTION_VIDEO_URL`은 이의 있음 장면의 마지막 대체 설정으로 계속 지원합니다.

현재 manifest에는 실제 영상이 없습니다. 이번 작업에서 Higgsfield 생성 요청은 계정 플랜 제한으로 거절되었으며 완료된 영상이나 생성 작업 ID는 없습니다. 런타임은 완료된 영상만 재생하며 생성 API를 호출하거나 요금을 발생시키지 않습니다. API 비밀키를 클라이언트에 넣지 않습니다. 실제 영상 재생 성공 검증은 유효한 에셋 연결 후 필요하며, 영상 미설정·404 대체 연출과 전체 사건 진행은 검증했습니다.

검증: 규칙·이동·영상 설정·이전 저장 호환 테스트 30개, TypeScript 검사, 프로덕션 빌드 통과. 브라우저에서 형사 사건 증거 수집·합성부터 5단계 조문 퍼즐, 세 차례 반박과 에필로그까지 S등급 완료를 확인했습니다.

## 플레이 가이드

달력·안내문·기록 단말에서 증거와 법전 카드를 모으고 원본 두 개(`a`, `b`)를 합성해 `c`를 만듭니다. 사건별 증거 종류가 모두 모이면 기관에 입장할 수 있습니다. 기관에서는 ① 적용 조문 고르기 ② 접수·청구 방식 퀴즈 ③ 요건판에 증거 채우기 ④ 진술을 증거와 조문으로 반박 ⑤ 마무리 절차 퀴즈를 차례로 풉니다. 계약 사건은 우체국에서 수신인 ‘굿즈 판매점’, 발신인 ‘김하루’, 청구 취지 ‘계약 취소 및 대금 반환’을 선택해야 내용증명이 접수됩니다.

이동·새 조사·실패 퍼즐·합성·상담·추궁은 1턴, 조문 퍼즐에서 틀린 답도 1턴이며 실수로 기록됩니다. 같은 공간 이동, 완료 조사, 중복 상담은 차감하지 않습니다. 정답 제시와 진술 넘기기는 턴을 소모하지 않고, 마지막 턴을 소모하면 게임오버입니다. 실수 횟수로 S(0회)·A(2회 이하)·B(4회 이하)·C 등급을 매깁니다.

## 교육상 구분

- 24턴은 게임 규칙이며 실제 법정기간이 아닙니다. 형사소송법 제245조의7 제3항의 이의신청 기간(통지를 받은 날부터 3개월, 정당한 사유 시 연장 가능)은 2026. 8. 4. 개정으로 신설된 조항으로, 에필로그 퀴즈에서 다룹니다.
- 조문 원문은 국가법령정보센터에서 2026-10-06에 확인한 현행 조문입니다. 법이 개정되면 사건별 데이터 파일(`criminal.ts`·`labor.ts`·`tort.ts`·`contract.ts`·`constitution.ts`)의 조문 카드를 갱신해야 합니다. 재산상 손해·인과관계·과잉금지원칙의 단계는 조문에 직접 쓰여 있지 않은 판례·통설상 기준으로 표시했습니다.
- 형사 사건은 추가 수사로 끝납니다. 발송지 모순만으로 사기 고의·유죄·배상명령이 확정되지 않습니다.
- 노동 사건은 상시 5인 이상, 주 20시간 소정근로 및 개근으로 설정. 노동청의 임금 진정과 노동위원회의 해고 구제는 별도 절차입니다.
- 계약 사건은 법정대리인 동의 없음, 처분 허락 범위 초과, 속임수 및 추인 없음으로 한정합니다. 내용증명은 내용의 진실성을 보장하지 않습니다.
- 강제적 게임 셧다운제는 2022-01-01 폐지. 헌법 사건은 새로운 가상 법률과 가상 결론이며 적법요건 충족을 가정합니다.
- 증거 합성은 논리 정리이며 독립적인 법적 효력 부여가 아닙니다. 실제 위법수집증거의 취급은 절차마다 다릅니다.
